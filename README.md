# 🐉 OpenClaw Time Machine Manager

A professional backup and restore utility for OpenClaw, optimized for M4 Mac (arm64).
专为 OpenClaw 设计的专业级备份与恢复管理工具，针对 M4 芯片深度优化。

## ✨ Features / 功能特性
- **Full-Pro Backup**: Snapshots of JSON, Workspace, Plugins, and Memory.
- **Bilingual UI**: Easy to use for global teams.
- **Safety First**: Auto-generates visible PRE-RESTORE snapshots.

## 🚀 Installation / 安装
1. Download `TimeMachine.command`.
2. Run `chmod +x TimeMachine.command` in terminal.
3. Double-click to launch.
